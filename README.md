# Configuration

Personal macOS development environment configuration.

## Install

```sh
curl -fsSL https://raw.githubusercontent.com/mac95sb/configuration/main/setup.sh | sh
```

## Self-hosted architecture

Native service configuration, backup scripts, and environment-file examples live in [`services/`](services/). See [the self-hosted architecture guide](docs/self-hosted-architecture.md) for resource routing, domains, and backup/restore expectations, then follow the [Phase 1 activation guide](docs/phase-1-activation-guide.md) to deploy safely.

The reusable application defaults are scaffolded separately at `~/Developer/template`.
